# 2026-08-11

## Session — retirement write barrier, failed-apply compensation, quick-tag preservation (v5.13.1)

Acting on the external review of `bugs/2026/08/plastic-bag-count`. D-4 stands: `plastic_bag` (92) is retired, `plasticBags` (149) survives.

- `AddTagsToPhotoAction::createTagLegacy()` now refuses a retired litter object, closing the legacy-format hole the CLO path already covered.
- `SyncQuickTagsAction` rejects presets on retired objects inside its transaction — `clo_id` validation only proves the pivot exists, and the pivot outlives the picker.
- `GetTagsController::index()` (`/api/tags`) filters retired objects, matching `/api/tags/all`.
- `olm:migrate-tag` apply is now preflight-first: expectations are checked read-only before any mutation, the picker close is re-verified under the closed door, and a failure before rows move reopens the picker — but only when that invocation closed it.
- An object already retired into a different survivor is refused outright instead of being silently re-pointed.
- Snapshot state gains `quick_tag_ids` (STATE_VERSION 4). A snapshot that cannot be persisted reopens the picker rather than leaving a retired object with no resumable record.
- Quick-tag collision deletion removed — `user_quick_tags` has no unique constraint on `(user_id, clo_id, type_id)`, so the old block destroyed valid presets. Presets are now repointed by captured id, late arrivals are swept, and every captured id is asserted at the target.
- `dropRetiredPivot()` fails instead of warning when references remain.
- Apply no longer clears state or reports "Applied" until the pivot is deleted and Redis reconciles both directions; a swallowed Redis error can no longer discard the resumable snapshot.
- `--verify` asserts the retirement facts (retired_at set, merged_into_id correct, survivor active, pivot absent, no lingering references) and checks the retired object reads zero across every scope the survivor occupies. The quick-tag count check is relabelled as a floor, not proof.
- `olm:fix-orphaned-tags` refuses to run unconditionally; its body is preserved unreachable as the historical record.
- CSV export shadow-object repair and its regression test reverted to merge-base — separate customer-visible contract change, patch preserved out-of-tree.
